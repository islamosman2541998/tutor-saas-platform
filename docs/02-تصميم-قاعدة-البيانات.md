# تصميم قاعدة البيانات

قاعدة بيانات واحدة (Single Database Multi-Tenancy) — كل جدول خاص بمدرس يحمل عمود `tenant_id`. الأنواع المالية `DECIMAL(10,2)` دائمًا. Soft Deletes مُشار إليها صراحة.

## ب. الهيكل الأكاديمي (Tenant-scoped)

### academic_years

## ي. ملاحظات تصميم عامة

- **لا جدول Media عام**: مسارات الصور أعمدة مباشرة في كل جدول (كافٍ ومطابق لهيكل المجلدات `tenants/{tenant_id}/...`)، تجنبًا للتعقيد الزائد (قاعدة #62 في المتطلبات).
- **Enums**: تُمثَّل بـPHP Enum class + عمود `string`/`enum` في قاعدة البيانات (وليس Enum خام في Migration لضمان مرونة التعديل لاحقًا بدون ALTER معقّد في بعض المحركات).
- **JSON**: يُستخدم فقط في حالات مرنة حقيقية (لا يوجد حاليًا حقل JSON إجباري في التصميم؛ `preferred_subjects` تحوّل إلى Pivot Table كما هو موضح أعلاه).
- **Composite Indexes** تتضمن `tenant_id` دائمًا كعمود أول في كل جدول Tenant-scoped لضمان كفاءة الفلترة.
