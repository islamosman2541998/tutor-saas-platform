# خطة التنفيذ

تنفيذ تدريجي، Module بعد Module، بترتيب التبعيات. كل خطوة تُسلَّم كاملة (Migrations + Models + Policies + Actions/Services + Livewire + Views + اختبار يدوي) قبل الانتقال للتالية.

## الإعداد الأولي (مرة واحدة)
- إنشاء مشروع Laravel + تثبيت الحزم: Livewire 3، Tailwind، Spatie Permission (مع Teams)، Spatie Activity Log، Laravel Excel، مكتبة QR، Alpine.js.
- إعداد `.env` وقاعدة البيانات، تفعيل Queue (`database` أو `redis`)، إعداد Scheduler، إعداد Storage Symlink، إعداد Subdomains محليًا (`*.platform.test` عبر `hosts` أو TLD محلي).

## معايير الانتقال بين الخطوات
لا يُنتقل لخطوة جديدة قبل:
- Migration تعمل بدون أخطاء ويُتحقق من الـIndexes/Unique Constraints.
- Model + Policy + Global Scope (إن وجد) مطبَّقة ومُختبرة يدويًا (مستخدمان في Tenant مختلفَين).
- Livewire Component يعمل مع Validation ورسائل عربية وToast/SweetAlert مناسبة.
- لا Query غير محسّن ظاهر (فحص عبر `DB::listen` أو Debugbar أثناء التطوير).
